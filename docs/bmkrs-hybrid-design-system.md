# bmkrs. — Hybrid Design System

**Direction:** editorial meets creative technology. Keep the official bmkrs. logo and its approved variants intact. This system changes the surrounding art direction, layouts, typography, colour, motion and content hierarchy.

## Brand idea

An independent digital product studio that can think, design, build and deliver. Editorial design supplies character; technical precision supplies credibility. The site should feel like a considered independent publication that happens to make excellent digital products.

## Tokens

| Token | Value | Role |
|---|---|---|
| Carbon | `#171717` | Primary dark canvas and type |
| Warm paper | `#F3F0E9` | Primary light canvas |
| Signal | `#F15A3B` | Action, emphasis, full-stop motif |
| Stone | `#D8D3C9` | Rules, panels, secondary surfaces |
| Slate | `#777873` | Supporting text and metadata |
| Acid | `#D8EE72` | Rare data/status highlight |
| White | `#FFFFFF` | Clean contrast |

Typography: Cabinet Grotesk (display, existing local font), Inter/system sans (body), IBM Plex Mono/system mono (metadata). Use expressive, tightly tracked headlines; readable body copy; mono only for labels, project references and technical annotations.

Layout: max content width around 1440px; fluid page gutters; large vertical section rhythm; asymmetric two-column layouts; case-study imagery with varied aspect ratios. Avoid a repeated card grid as the default.
