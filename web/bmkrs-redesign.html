bmkrs homepage redesign — QA reference

The approved static prototype was provided in the build spec (Build Spec v1.0). The implemented homepage maps prototype layout and motion to the existing bmkrs palette (ink / paper / orange) and Cabinet Grotesk + Fragment Mono.

Side-by-side checks

  • 1440px — type scale, section spacing, hairline weights, snap easing
  • 1024px — grid breakpoints (arrive 2-col, packages 3-col)
  • 390px — single-column stacks, nav CTA only on mobile menu

Colour mapping (prototype → build)

  • chalk snap line → #FF4D00 orange
  • bone → #F1EFE8 paper
  • ink-2 → #211f1b ink-raised
